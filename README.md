# Android Assignment App

A comprehensive Android application demonstrating core development concepts across 8 chapters.

## 🚀 Features
- **Chapter 2 & 3:** Activity Lifecycle logs, Navigation with data passing, and Responsive UI (ConstraintLayout).
- **Chapter 4:** Data Persistence using SharedPreferences, Internal Storage, and a full SQLite Notes App.
- **Chapter 5:** Networking with REST API (JSON parsing) and Error Handling.
- **Chapter 6:** MVVM Architecture with ViewModel & LiveData, RecyclerView, and Fragments.
- **Chapter 7:** Hardware integration: Accelerometer, GPS Location, Camera, and Audio.
- **Chapter 8:** Security implementation with Data Encryption and Runtime Permissions.

## 🛠 Tech Stack
- **Language:** Kotlin
- **Architecture:** MVVM
- **Database:** SQLite
- **Network:** HttpURLConnection & Coroutines
- **UI:** XML (ConstraintLayout, LinearLayout)

## 📥 Installation
1. Clone the repository.
2. Open in Android Studio.
3. Build and run on an emulator or physical device.
